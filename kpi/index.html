  4. Второй вход: «вставьте ссылку на объявление»

Как считаем
  • Человек — браузер с первым подбором в неделе. Считаем только живых: есть след в счётчике посещений. Роботы, проверки команды и пробные подборы не считаются.
  • Неделя — 7 полных дней по Риге, последняя кончается вчера. Числа — по правилам официального суточного счёта.
  • Латвия — страна человека по счётчику посещений. Число посетителей сайта не мерило (встреча 06.11).
  • Одна проверка за раз в одной группе. Ответ — по сроку, записанному до запуска. Вывод утверждаем на пятничной встрече.
  • Новая версия и прежний подбор сравниваются без людей из рекламы; люди из рекламы — в карточке рекламы.
